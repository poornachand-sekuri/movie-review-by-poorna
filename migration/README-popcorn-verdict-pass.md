# Popcorn Verdict rewrite pass

Rules for this pass:
- Read the full review body before rewriting the verdict.
- Keep the verdict crisp enough for both home and review pages.
- Use simple, everyday language.
- Preserve the author's natural casual/sarcastic/emotional tone.
- Avoid polished critic-speak and generic AI summary language.
- Verdict must stand alone and make complete sense.
- Do not merely copy or truncate lines from the review.
